# Иконки веб-плеера

SVG скачаны из [официального репозитория Lucide](https://github.com/lucide-icons/lucide/tree/main/icons).
Исходные файлы сохранены без изменений; условия использования и уведомления об
авторских правах находятся в [LICENSE](LICENSE).

В `player.css` иконки подключены как CSS-маски: цвет наследуется от кнопки,
включая белые иконки на зелёном фоне. Внешние запросы для показа иконок не нужны.

| Файлы | Назначение |
| --- | --- |
| `play.svg`, `pause.svg` | Воспроизведение и пауза |
| `skip-back.svg`, `skip-forward.svg` | Предыдущий и следующий трек |
| `folder-up.svg`, `folder-down.svg` | Предыдущая и следующая директория |
| `folder-open.svg` | Показать файл в Finder |
| `shuffle.svg` | Перемешать треки |
| `list-music.svg` | Показать плейлист |
| `pencil.svg` | Редактировать |
