# musical-mind-palace
Разбираю свои музыкальные чертоги разума

## Скрипты

- [crawler](docs/scripts/crawler.md) — собирает музыкальные папки из заданных
  каталогов, создаёт индексы и проверяет структуру итоговой библиотеки.
- [tidy_up_index](docs/scripts/tidy_up_index.md) — раскладывает ресурсы музыкальных
  папок по категориям, сохраняя совпадающие имена с номерным суффиксом.
