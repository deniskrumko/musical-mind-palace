# Сбор музыкальных папок

Скрипт `src/scripts/crawler.py` рекурсивно ищет музыкальные папки, записывает
исходный путь в `INDEX.md`, очищает название и **перемещает** папки в общий каталог.

## Настройка и запуск

Заполните константы в начале скрипта, например:

```python
ROOT_MUSIC_DIR = Path("/Users/me/Music")
INPUT_MUSIC_DIRS: list[Path] = [
    ROOT_MUSIC_DIR / "Drafts",
    ROOT_MUSIC_DIR / "Archive",
]
OUTPUT_INDEX_DIR = ROOT_MUSIC_DIR / "Index"
```

Входные каталоги должны находиться внутри `ROOT_MUSIC_DIR`.
Отсутствующие входные папки пропускаются с сообщением и полным путём;
остальные входы продолжают обрабатываться. Если отсутствуют все входы,
скрипт переходит к валидации выходного каталога без переноса папок.
Относительные пути отсчитываются от текущего рабочего каталога; `~` раскрывается.
По умолчанию список входов пуст: до его заполнения скрипт завершается с пояснением.
Выходной каталог создаётся автоматически.

Из корня проекта выполните:

```sh
PYTHONPATH=src uv run src/scripts/crawler.py
```

## Поиск

- Музыкальной считается папка, непосредственно содержащая файл с расширением
  из `CATEGORY_EXTENSIONS` в `src/core/file_extensions.py` (включая изображения),
  либо пакет-каталог `.logicx` и `.band`. Регистр расширения не учитывается.
- После обнаружения такой папки её содержимое переносится целиком. Вложенные
  папки больше не рассматриваются как самостоятельные песни.
- Внутренности пакетов `.logicx` и `.band` не сканируются.
- Выходная папка и всё её содержимое **никогда не участвуют в поиске**, в том
  числе если выход указан среди входов.
- Повторные и пересекающиеся входы не приводят к повторной обработке песни.
- Символические ссылки не участвуют в поиске. Ссылки внутри уже найденной
  музыкальной папки перемещаются вместе с ней как часть её содержимого.
- Если найденная музыкальная папка содержит выходной каталог, скрипт сообщает
  об ошибке до начала переноса.

## Индекс и название

В музыкальной папке создаётся или обновляется `INDEX.md`:

```markdown
## Original folder
Drafts/Hello (test)
```

Путь записывается относительно `ROOT_MUSIC_DIR`, до очистки названия.
Теги уникальны: прежнее значение `Original folder` заменяется текущим путём.
Другие теги и свободное описание сохраняются. Формат и API описаны в
[документации индексов](../index_files.md).

Из названия удаляются все завершённые фрагменты в круглых скобках, включая
вложенные, а повторяющиеся пробелы схлопываются: `Hello (demo) (2024)` → `Hello`.
Если результат пуст, сохраняется исходное название. Несбалансированные скобки
остаются в названии. Имена файлов и вложенных папок при обычном переносе сохраняются.

## Совпадение названий

Если имя назначения занято, скрипт предлагает:

- `m` — рекурсивно объединить папки;
- `n` — выбрать свободное имя `Hello (2)`, затем `Hello (3)` и так далее;
- `q`, пустой ответ или Ctrl+C — остановить выполнение.

Если назначение является файлом или символической ссылкой, доступен номерной
суффикс либо остановка. Решение запрашивается до изменения исходного индекса.
При завершении ввода без ответа текущая папка также остаётся на месте.

При объединении совпадающие файлы получают номер перед последним расширением:
`track.mp3` → `track (2).mp3`. Одноимённые обычные подпапки объединяются рекурсивно.
Пакеты `.logicx` и `.band` всегда сохраняются целиком: `Session.logicx` → `Session (2).logicx`.
Существующие файлы не перезаписываются.

Два `INDEX.md` объединяются отдельно: свободные описания сохраняются, а для
совпадающих тегов берётся значение из переносимой папки. Это относится и к
`Original folder`: он хранит один актуальный путь, а не историю источников.
После успешного объединения опустевшая исходная папка удаляется.

## Валидация

После завершения переноса скрипт проверяет весь `OUTPUT_INDEX_DIR`, включая
папки, находившиеся там до запуска:

- В каждой папке первого уровня должен быть обычный файл `INDEX.md`.
  Если его нет, выводится `Не найден файл индекса: <путь>`.
- Во вложенных папках любой глубины файлов `INDEX.md` быть не должно.
  Для каждого найденного файла выводится `Найдены вложения: <путь>`.
  Пакеты `.logicx` и `.band` считаются файлами, их содержимое не проверяется.
- Символические ссылки не обходятся; ссылка вместо основного индекса
  не считается обычным файлом индекса.

Проверка только сообщает о нарушениях, не создавая и не удаляя индексы.
Она выводит общее число нарушений либо сообщение об успешной валидации.
При нарушениях скрипт завершается с кодом `1`. После ошибки переноса или отмены
валидация не запускается.

## Ошибки и повторный запуск

При ошибке выполнение останавливается с кодом `1`, при отмене — `130`,
после успеха — `0`. Скрипт выводит каждый завершённый перенос и итоговое число папок.
Ошибки чтения каталогов не пропускаются молча. Символическая ссылка вместо
`INDEX.md` считается ошибкой.

Переносы выполняются последовательно, без общего отката. При ошибке часть
папок или содержимого объединяемой папки уже может быть перенесена; индекс также
может быть обновлён. Перед работой с единственной копией библиотеки сделайте резервную копию.
При следующем запуске выходной каталог пропускается, а поиск выполняется по
оставшимся входным данным. Очищенные папки, уже перенесённые в выход, повторно
не обрабатываются.

Расширения проектов берутся из `CATEGORY_EXTENSIONS["logic"]`: каждый такой
проект считается цельным файлом, не обходится и не объединяется с другим проектом.
Это правило также действует при валидации, сортировке и проверке пустых папок.
