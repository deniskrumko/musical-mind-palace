# Запуск веб-плеера

Скрипт `src/scripts/run_web_player.py` запускает FastAPI-плеер в одном процессе.
При старте он собирает общую очередь из музыкальных директорий `INDEX_DIR`.

```bash
make local_webplayer
make webplayer
```

Первая команда слушает `0.0.0.0:8090`, вторая определяет IPv4 сетевого интерфейса
через стандартный модуль Python `socket`.
Для подключения с телефона откройте `http://<IP компьютера>:8090` в одной WiFi-сети.

```bash
PYTHONPATH=src uv run src/scripts/run_web_player.py --host 127.0.0.1 --port 8091 --index-dir /путь/к/INDEX
PYTHONPATH=src uv run src/scripts/run_web_player.py --auto-host
```

Параметры:

- `--host` — адрес прослушивания, по умолчанию `0.0.0.0`.
- `--auto-host` — автоматически определить IPv4; несовместим с `--host`.
- `--port` — порт, по умолчанию `8090`.
- `--index-dir` — библиотека, по умолчанию `INDEX_DIR` из `scripts`.

Воспроизведение начинается по нажатию Play. Для обновления списка файлов
перезапустите сервер. Shuffle меняет будущую очередь на сервере, сохраняя текущий
трек и историю. Подробное поведение описано в [документации плеера](../web_player.md).
