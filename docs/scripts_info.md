# Скрипты

- Размещай все скрипты в каталоге `src/scripts/`.
- В начале файла скрипта должна быть строка документации с описанием и командой запуска:

```py
"""Собирает музыкальные папки в индекс.

При необходимости добавь подробное описание.

Запуск:
    PYTHONPATH=src uv run src/scripts/crawler.py
"""
```

- Запускай скрипты командой `PYTHONPATH=src uv run ...`.
- Для каждого скрипта должна быть документация в каталоге `docs/scripts/` со ссылкой на неё в `README.md`.
