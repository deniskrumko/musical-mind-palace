# Файлы INDEX.md

Каждая музыкальная директория содержит файл-индекс `INDEX.md`, который используется в дальнейшнем при поиске файлов, записи тегов, текста песни и т.д.

За управление тегами отвечает модуль `src/index/`.

# Что такое музыкальная директория

По сути это папка в которой есть файл-индекс и куча разных файлов любых форматов. Главное правило - файл-индекс!

```
INDEX.md
folders/
file.m4a
```

# Формат тега

Сам файл индекса представляет из себя Markdown файл в следующем формате:

```markdown
## <tag_name>
<tag_value>

## <tag_name>
<tag_value>
```

**Правила:**

- Если тег с таким же именем существует - то при апдейте индекса он обновляется (не дописывается!)
- Значение тега может быть многострочным, отделяющим всегда является имя тега
- Имя тега всегда начинается с `##` с самого начала строки
- Если строка начинается с `###` или `##` где-то не в начале строки - это не название тега, а его значение
  
  ```markdown
  ## tag1
  tag value
  
  ### this is also value
  
  ## tag 2
  But also ## this is value of tag 2
  ```

- Если до первого тега что-то идет, то оно не трогается - это свободная часть описания файла, сколько угодно строк, любой текст:
  
  ```markdown
  # Hello World
  Lorem Ipsum...
  [My website example](https://github.com/deniskrumko)
  
  ## tag1
  tag value
  ```

## Произвольный тег

Например, при парсинге директорий скриптом `src/scripts/crawler.py` добавляется тег с исходным путем до директории

```markdown
## Original folder
Acoustic/Bad/The Wait (sad angry parts)
```

Это произвольный тег, у которого нет заранее определенных требований и формата.

## API модуля

Модуль `src.index` экспортирует Pydantic-модель `Index` и константу
`INDEX_FILENAME = "INDEX.md"`. Реализация находится в `src/index/resources.py`:

```python
from pathlib import Path
from src.index import Index

path = Path("/music/Hello/INDEX.md")
index = Index.load(path)
index.set("Mood", "Спокойная\nАкустическая")
index.save(path)
```

- `Index.load(path)` читает UTF-8; для отсутствующего файла создаёт пустой индекс.
- `Index.parse(text)` разбирает строку, `render()` собирает Markdown.
- `set(name, value)` добавляет тег либо заменяет его значение.
- `tags` содержит уникальные имена и значения, `description` — свободный текст
  до первого тега. При чтении повторяющихся тегов сохраняется последнее значение.
- `merge(incoming)` сохраняет свободные описания обоих индексов и заменяет
  совпадающие теги значениями входящего индекса.
- `save(path)` записывает индекс; родительская папка должна существовать.

Символические ссылки вместо файла индекса отклоняются при чтении и записи.
При пересборке индекса промежутки между тегами нормализуются; свободное описание
перед первым тегом сохраняется.
